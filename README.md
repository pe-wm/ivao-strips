# Peru Division IVAO Strips for WordPress

Plugin para gestión de strips de controladores de IVAO Perú

## Características
- Permite crear, modificar, tranferir y borrar strips. Guarda sesión por Posición controlada y permite crear presets.
- Shortcode `[strips_atc]`
- Fichero de posiciones modificables que en principio incluye las posiciones de Perú.

## Instalación
1. Descarga o clona este repositorio en `wp-content/plugins/ivao-strips`
2. Activa el plugin desde el panel de WordPress
3- Crear una carpeta stripsaves dentro de wp-content/uploads
4- añadir el shortcode [strips_atc] en una nueva página
